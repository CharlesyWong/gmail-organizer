Gmail Organizer

Privacy Policy

Effective 23 October 2026

Gmail Organizer is a local, open-source tool. This policy explains what it accesses, where data stays, and how to delete it.

What the app accesses

  • Gmail message metadata: message ID, thread ID, sender, subject, date, label IDs, and internal date.
  • Gmail labels needed to reuse or create Auto/<Category> labels.

It does not download message bodies, attachments, contacts, calendar data, or other Google data.

Why it accesses data

To classify messages using rules you configure and to add labels so your inbox is easier to triage.

Where data is processed and stored

  • All processing happens locally on the device where you run the tool.
  • The OAuth token is stored locally in .secrets/token.json.
  • The incremental watermark and run summary are stored in data/state.json.
  • Logs are stored in logs/. Default INFO logs do not include sender or subject; DEBUG logs (--verbose) may include sender and subject and remain local.
  • The tool does not send Gmail data to the project owner or any server.

Sharing and use

No sale, sharing, or transfer of Google user data to third parties. Google user data is used only to provide the labeling functionality you request. It is not used for advertising, and it is not used to train or improve generalized AI or machine learning models. This website is static and uses no advertising, analytics, or tracking.

Google API Limited Use

Gmail Organizer's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

  • Revoke the app's access at Google Account permissions.
  • Delete .secrets/token.json, data/state.json, and logs/ from your machine.
  • Remove any Auto/* labels you no longer want in Gmail.

Deleting local files removes stored credentials and state; it does not remove labels already applied in Gmail.

Security

Tokens are kept local and excluded from git. The tool requests gmail.modify, the narrowest scope used for metadata reads and label application. Do not run the tool on a shared or untrusted machine.

Changes

Material changes will be reflected on this page with a new effective date.

Contact

Questions or data requests: open an issue at github.com/CharlesyWong/gmail-organizer/issues. For security reports, use the repository's private security advisory flow.

Gmail Organizer is an independent open-source project, not affiliated with Google. Gmail is a trademark of Google LLC.
